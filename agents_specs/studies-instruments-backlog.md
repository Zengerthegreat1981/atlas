# قائمة انتظار الفئات — الدراسات المؤسِّسة وأدوات القياس النفسي

نفس آلية `schools-backlog.md` و`landmark-books-backlog.md` بالظبط (`[ ]` لسه، `[~]` شغال عليه دلوقتي،
`[x]` خلصان) — كل بند هنا "فئة موضوعية" مش دراسة/أداة بعينها مسبقاً، لأن مفيش قائمة جاهزة زي المدارس؛
الفئة نفسها هي وحدة البحث (نفس منطق الكتب بالضبط، بس بفئات موضوعية بدل عصور زمنية).

**افتح `landmark-studies-instruments-pipeline.md` أولاً** قبل ما تبدأ أي فئة هنا — هو اللي فيه شرح
الدورة الكاملة، الملف ده بس قائمة التتبّع.

---

## قسم أ — دراسات وتجارب مؤسِّسة (`stu-`)

- [x] علم النفس الاجتماعي الكلاسيكي — الطاعة والامتثال والسلطة (ميلغرام، آش، زيمباردو/سجن ستانفورد، شريف/الكهف)
- [x] علم النفس الاجتماعي الكلاسيكي — التنافر المعرفي والإسناد والتحيز (فستنجر، هايدر، روس/الخطأ الإسنادي الأساسي)
- [x] علم النفس الاجتماعي الكلاسيكي — التأثير الجمعي وتأثير المتفرج (لاتانيه ودارلي، تجارب المساعدة/اللامبالاة الجماعية)
- [x] السلوكية والتعلّم الشرطي (بافلوف، واطسون/ليتل ألبرت، سكينر، ثورندايك، جارسيا/النفور من الطعم)
- [x] النمو والتعلّق (هارلو/قردة السلك والقماش، أينسورث/الموقف الغريب، بولبي، تجارب الحرمان الأمومي)
- [x] بياجيه والنمو المعرفي عند الأطفال (تجارب الحفظ، نظرية العقل، التقليد المؤجل)
- [x] الذاكرة والنسيان الكلاسيكية (إبنغهاوس، بارتليت/"حرب الأشباح"، سبيرلينج/الذاكرة الأيقونية، ميلر/الرقم السحري سبعة)
- [x] الذاكرة الزائفة وموثوقية الشهادة (لوفتوس وتضليل الشهود، ذاكرة الصدمة المستعادة، الجدل حولها)
- [x] العلم العصبي المعرفي المبكر (سبيري/الدماغ المشقوق، بروكا وفيرنيكه كحالات مؤسِّسة لو لسه غير مكتوبة، H.M./ميلنر والذاكرة)
- [x] الشرطية الاجتماعية والتعلّم بالملاحظة (باندورا/دمية بوبو، التعلّم الاجتماعي المعرفي)
- [x] العجز المُتعلَّم والتفاؤل/التشاؤم المُفسَّر (سليجمان، تجارب الكلاب الأصلية والامتدادات البشرية)
- [x] التصنيف الإكلينيكي والوصمة (روزنهان/"عن كونك سليماً في أماكن مجانين"، الجدل حول التشخيص)
- [x] التوافق الاجتماعي والامتثال الجمعي في الأطفال والمراهقين (لو فيه دراسات كلاسيكية غير مغطاة بعد بخلاف آش)
- [x] دراسات الحرمان الحسي والبيئة المبكرة (رومانيا/أيتام تشاوشيسكو كحالة موثقة حديثاً، تجارب الحرمان الحسي المبكرة)

- [x] دراسات وتجارب إضافية في التعلّم والحافز (تريبليت والتيسير الاجتماعي لو غير مغطى، دراسات هوثورن، تجارب دويك حول عقلية النمو، دراسات ديسي وراين للتحفيز الداخلي)
- [x] دراسات الشخصية وطول العمر النفسي (دراسة تيرمان الطولية للعبقرية، دراسة هارفارد للنمو البالغ، دراسة ماركيز الطولية للمرونة النفسية لو موثقة أكاديمياً)
## قسم ب — أدوات قياس نفسي (`ins-`)

- [x] أدوات قياس الذكاء العام (ستانفورد-بينيه، وكسلر للبالغين WAIS، وكسلر للأطفال WISC، مصفوفات رافن التتابعية)
- [x] أدوات قياس الشخصية متعددة الأبعاد (MMPI، عامل الشخصية الخمسة الكبرى/NEO-PI-R، كاتل 16PF)
- [x] أدوات الإسقاط الشخصية (اختبار رورشاخ، اختبار تفهم الموضوع TAT، اختبار تكميل الجمل)
- [x] مقاييس الاكتئاب والقلق الإكلينيكية الشائعة (بيك للاكتئاب BDI-II، PHQ-9 لو غير موجودة، مقياس هاملتون للاكتئاب HAM-D، مقياس القلق لدى سبيلبرغر STAI لو مختلف عن الموجود بالفعل)
- [x] مقاييس الوسواس القهري والصدمة الإكلينيكية (Y-BOCS، قائمة أعراض ما بعد الصدمة PCL-5)
- [x] الأدوات العصبية النفسية (اختبار بندر-غشطالت البصري الحركي، اختبار ربط المسارات Trail Making Test، مقياس وكسلر للذاكرة WMS)
- [x] أدوات التطور والسلوك عند الأطفال (قائمة سلوك الطفل CBCL، مقاييس فاينلاند للسلوك التكيفي)
- [x] أدوات قياس التعلّق والعلاقات البالغة (مقابلة التعلّق للبالغين AAI، مقياس الخبرات في العلاقات الحميمة ECR)
- [x] أدوات قياس نوعية الحياة والرفاه النفسي العام (مقياس الرضا عن الحياة SWLS، مقاييس الرفاه الذاتي الشائعة أكاديمياً — تجنّب أي أداة تجارية/غير أكاديمية)

- [x] أدوات قياس القلق الاجتماعي والرهاب المحدد تحديداً (مقياس ليبوفيتز للقلق الاجتماعي LSAS، مقياس الرهاب الاجتماعي SPIN) — لو مختلفة عن GAD-7/STAI الموجودين بالفعل
- [x] أدوات قياس الإدمان والسلوكيات القهرية (AUDIT لاضطراب الكحول، DAST لتعاطي المخدرات، مقياس يونغ لإدمان الإنترنت) — تأكد من عدم تكرار مع أي أداة موجودة أصلاً في content/ar/instruments/

## ملاحظات

- الترتيب داخل كل قسم أولوية تقريبية (الأكثر شهرة أكاديمياً أولاً)، لكن مش صارم زي `schools-backlog.md`
  — يمكن تبديل الترتيب لو فئة معينة أسهل بحثاً في لحظة معينة، المهم الإقفال الكامل لكل فئة قبل الانتقال.
- لو أثناء البحث في فئة اكتشفت فئة فرعية مهمة مش موجودة هنا (مثلاً "أدوات قياس القلق الاجتماعي تحديداً"
  كفئة منفصلة)، أضفها كسطر `[ ]` جديد في آخر القسم المناسب بدل تجاهلها أو حشرها بالغلط في فئة تانية.
- هذا الملف مسؤولية هذا المسار (`landmark-studies-instruments-pipeline.md`) فقط — لا علاقة له
  بـ`schools-backlog.md` ولا `landmark-books-backlog.md` ولا `philosophy-schools-backlog.md`.
