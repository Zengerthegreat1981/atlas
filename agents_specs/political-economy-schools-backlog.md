> ⚠️ **حدُّ القسم**: **سوسيولوجيا الاقتصاد مغطّاةٌ من جلسة علم الاجتماع**
> (`sch-economic-sociology-embeddedness`، `sch-bourdieu-field-capital`،
> `sch-srnicek-platform-capitalism`، `sch-zuboff-surveillance-capitalism`،
> `sch-boltanski-chiapello-capitalist-spirit`). **اربط ولا تكرّر.**
> و**الاقتصادُ السلوكيّ** أعلامُه في الأطلس تحت `psychology` (كانمان، تفرسكي، ثالر) —
> اربط بهم ولا تنشئ نظائر. والعنوانُ المكرَّرُ **فحصٌ قاطع**.

## 1. التقليدُ ما قبل الحديث والعربيّ
- [ ] الاقتصادُ في المقدّمة الخلدونية (العصبيةُ والجباية ومنحنى الضرائب)
- [ ] الخراجُ والحسبةُ في الفقه الإسلاميّ (أبو يوسف، ابن تيمية، المقريزي في الغلاء)
- [ ] الاقتصادُ الأخلاقيُّ الأرسطيّ (الكريماتستيك، الربا، العدالةُ التبادلية)
- [ ] المدرسةُ السكولائيةُ الثانيةُ وسالامانكا (نظريةُ القيمة والسعر العادل)
- [ ] المركنتيليةُ والكاميرالية
- [ ] الفيزيوقراطيةُ وجدولُ كِنِيه الاقتصاديّ

## 2. الكلاسيكيةُ السياسية
- [ ] الاقتصادُ السياسيُّ الكلاسيكيُّ عند آدم سميث (تقسيمُ العمل، اليدُ الخفية، *ثروة الأمم*)
- [ ] ريكاردو والميزةُ النسبيةُ والريع
- [ ] مالتوس ونظريةُ السكان
- [ ] جون ستيوارت مل والنفعيةُ الاقتصادية
- [ ] ساي وقانونُ الأسواق

## 3. النقدُ الماركسيُّ والاشتراكيّ
- [ ] نقدُ الاقتصاد السياسيِّ عند ماركس (قيمةُ العمل، فائضُ القيمة، صنميةُ السلعة)
- [ ] الإمبرياليةُ وتراكمُ رأس المال (لوكسمبورغ، لينين، هيلفردنغ)
- [ ] نظريةُ التبعيةِ ونظامُ العالم (برِبيش، فرانك، أمين، والرشتاين)
- [ ] النظريةُ التنظيمية ومدرسةُ الانتظام (Régulation — أغليتّا، بوايِيه)
- [ ] الماركسيةُ التحليليةُ والأناليتيكال (كوهين، رومر، إلستر)
- [ ] الاشتراكيةُ الطوباويةُ والتعاونية (أوين، فورييه، برودون)

## 4. الحدّيةُ والنيوكلاسيكية
- [ ] الثورةُ الحدّية (جيفونز، مِنغِر، فالراس)
- [ ] التوازنُ العامُّ والاقتصادُ الرياضيّ (فالراس، آرو-ديبرو)
- [ ] مارشال والاقتصادُ الجزئيُّ الكلاسيكيُّ الجديد
- [ ] باريتو والكفاءةُ الاقتصاديةُ الاجتماعية
- [ ] نظريةُ الاختيار العقلانيِّ والإنسانُ الاقتصاديّ (Homo Economicus) — ونقدُها

## 5. الكينزيةُ والاقتصادُ الكلّيّ
- [ ] الثورةُ الكينزية (*النظرية العامة*، الطلبُ الفعّال، الأرواحُ الحيوانية)
- [ ] التركيبُ النيوكلاسيكيُّ الكينزيُّ (هيكس، صامويلسون)
- [ ] ما بعد الكينزية (روبنسون، كالِتْسكي، مينسكي وفرضيةُ الهشاشة المالية)
- [ ] النقديةُ ومدرسةُ شيكاغو (فريدمان، التوقّعاتُ الرشيدة، لوكاس)
- [ ] النظريةُ النقديةُ الحديثةُ (MMT) وجدلُها

## 6. النمسويةُ والليبراليةُ الجديدة
- [ ] المدرسةُ النمسوية (مِنغِر، ميزس، مسألةُ الحساب الاشتراكيّ)
- [ ] هايك والمعرفةُ الموزَّعةُ والنظامُ العفويّ
- [ ] مدرسةُ مونت بيلران ونشأةُ النيوليبرالية
- [ ] مدرسةُ الاختيار العامِّ (بيوكانان، تَلُّوك)
- [ ] الأورديليبراليةُ الألمانيةُ والسوقُ الاجتماعيّ

## 7. المؤسّسيةُ والتاريخيةُ والتطوّرية
- [ ] المؤسّسيةُ الأمريكيةُ القديمة (ڤيبلن، كومونز، ميتشل)
- [ ] المؤسّسيةُ الجديدةُ وتكاليفُ المعاملات (كوز، ويليامسون، نورث)
- [ ] إدارةُ المشاعات (أوستروم — وجائزةُ نوبل 2009)
- [ ] الاقتصادُ التطوّريُّ والابتكار (شومبيتر والتدميرُ الخلّاق، نلسون ووينتر)
- [ ] المدرسةُ التاريخيةُ الألمانية (شمولّر، جدلُ المناهج Methodenstreit)

## 8. الأخلاقُ والتنميةُ والقدرات
- [ ] بولاني والتحوُّلُ الكبيرُ والاندماجُ الاجتماعيّ (*The Great Transformation*)
- [ ] مقاربةُ القدرات (أمارتيا سِن، مارثا نوسباوم) — **`thk-sen` موجودٌ تحت `philosophy`**
- [ ] اقتصادياتُ التنميةِ ونقدُها (لويس، إستِرلي، بانرجي ودوفلو والتجاربُ العشوائية)
- [ ] الاقتصادُ النسويُّ والعملُ غيرُ المأجور (Waring، Folbre)
- [ ] اقتصادياتُ اللامساواة (پيكيتي، ميلانوفيتش، أتكنسون)
- [ ] الاقتصادُ البيئيُّ واقتصادُ ما بعد النموّ (Degrowth، Daly، Raworth)

## 9. الاقتصادُ والنفس
- [ ] الاقتصادُ السلوكيُّ وبرنامجُ الاستدلالات والتحيّزات — **اربط بـ`thk-kahneman`، `thk-amos-tversky`، `thk-rkthaler`**
- [ ] نظريةُ التوقُّع (Prospect Theory) — **قد تكون مغطّاةً في علم النفس؛ افحص أوّلاً**
- [ ] اقتصادُ السعادةِ والرفاه (Easterlin Paradox)
- [ ] سيكولوجيا الفقر والندرة (Mullainathan & Shafir)
- [ ] الوصمُ والدَّينُ والصحّةُ النفسية — **جسرٌ إلى علم النفس الإكلينيكيّ**
