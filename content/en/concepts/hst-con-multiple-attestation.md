# Multiple Attestation and Source Corroboration

Ancient historians strengthened claims through multiple independent sources testifying to the same events.

## Definition and Core Concept

When multiple independent sources attested to the same claim, ancient historians regarded it as more reliable. Agreement among sources suggested truth; disagreement required explanation and evaluation. Multiple attestation became a criterion for evaluating claims.
