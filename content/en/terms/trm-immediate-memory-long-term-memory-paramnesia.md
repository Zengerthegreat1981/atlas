# Immediate memory, Long-term memory, Paramnesia,

Short-term memory. Memory span: A well-known measure of an individual’s capacity for retaining small units of meaningless information over a brief period of time. In a typical measure of memory span, a list of digits is read out to someone at a regular pace.
