# Dual leadership: See Co-therapy.

Dual-memory theory: A model of memory first proposed by William James, in 1890, and later developed by (among other) Miller and Atkinson and Shiffrin. Dual memory theory postulates two independent memory systems, a limited-capacity, immediate or short-term memory, and a large-capacity, long-term memory.
