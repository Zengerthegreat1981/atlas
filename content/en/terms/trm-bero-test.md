# Bero test.

Test, beta: A set of mental tests used in the U.S. Army in 1917–18, designed for illiterates. Instructions are given in signs and the material is pictorial in character, in contrast to alpha tests, which are carried out verbally. Test, block design: A performance test in which the subject tries to match standard designs using coloured blocks ; used as a measure of intelligence and as an indicator
