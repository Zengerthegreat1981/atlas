# Aptitude Tests

Aptitude tests are standardized tasks designed to indicate an individual’s future job proficiency or success in training. Some tests have been specifically developed for this purpose (for example, name and number comparison tests for selecting clerical workers), whilst others have been borrowed from educational, clinical and research use (for example, Cattell’s 16 Personality Factor Questionnaire)
