# PROBLEM SOLVING 325

by Wason and others using the 4-card task. In this task, subjects have to say which cards need to be turned over to test a conditional rule relating the showing and the not-showing faces of the cards. For example, the rule might be ‘if there is an “A” on one side there is a “4” on the other side’. Given cards showing A, B, 4 and 7, which need be turned over? (Answer, A and 7). Most subjects do not
