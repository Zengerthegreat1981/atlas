# أنثروبولوجيا الذاكرة الجمعية للجائحة (Pandemic Memory Anthropology)

## الجدل

جدل أنثروبولوجي معاصر حول أنثروبولوجيا الذاكرة الجمعية للجائحة.

## الأطراف

- الاتجاه الثاني: الرؤية المعاصرة

## المناقشة

Pandemic Memory Anthropology يمثل نقاشاً حياً في المجتمع الأنثروبولوجي حول الاتجاهات الراهنة.
