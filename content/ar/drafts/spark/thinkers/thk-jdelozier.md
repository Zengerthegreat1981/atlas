# جوديث دِلوزييه

مدربة ومطورة أمريكية بارزة في مجال البرمجة اللغوية العصبية (NLP)، شاركت مع جون غريندر (John Grinder) وريتشارد باندلر في الصياغات الأولى للحقل منذ عام 1975.

## الكود الجديد للبرمجة اللغوية العصبية (New Code NLP)

طوّرت دِلوزييه مع جون غريندر «الكود الجديد» (New Code NLP) في الثمانينيات، لمعالجة أوجه القصور في النماذج المبكرة وتأكيد دور الحالات الذهنية-الجسدية العليا (High Performance States) ومشاركة العقل اللاواعي في إحداث التغيير السلوكي التلقائي. ألّفت مع غريندر كتاب *Turtles All the Way Down* (1987) لربط البرمجة اللغوية العصبية بنظرية النظم وعلم الأحياء الإدراكي عند غريغوري باتيسون. وتأثرت بمناهجها برامج توني روبنز (Tony Robbins).
